# CareerVector Manual QA

Manual functional testing project for the CareerVector web application. This repository is inspired by the supplied OpenCart QA deliverables and adapts their structure—test plan, test scenarios, test execution, RTM, and bug reporting to CareerVector.

## Application Under Test
https://ragapp-mmuhxs8autgvtc7vzxwbcz.streamlit.app/

## Repository
https://github.com/jobayertalha/careervector-qa-automation

## Deliverables
- `CareerVector_Manual_Test_Plan.pdf` — scope, strategy, environment, entry/exit criteria, risks and deliverables.
- `CareerVector_Manual_Test_Scenarios.xlsx` — scenario inventory, priority and test-case counts.
- `CareerVector_Manual_Test_Execution.xlsx` — detailed manual test cases and execution fields.
- `CareerVector_Manual_RTM.xlsx` — feature/scenario-to-test-case traceability.
- `CareerVector_Manual_Bug_Report.xlsx` — defect logging template and reporting guidance.

## Current Coverage
14 test scenarios and 24 manual test cases covering onboarding, homepage, navigation, CV analysis, JD matching, quiz, theme/UI and error handling.

## Execution Status
All manual test cases are initially marked `NOT RUN`. Update actual result, execution result, tester, date and evidence only after performing the manual test. No application defects are pre-populated; log only reproducible findings.

## Suggested Manual Execution Workflow
1. Read the test plan.
2. Review scenario inventory and priorities.
3. Execute cases in `CareerVector_Manual_Test_Execution.xlsx`.
4. Record PASS / FAIL / BLOCKED / NOT APPLICABLE and actual observations.
5. Log reproducible failures in `CareerVector_Manual_Bug_Report.xlsx`.
6. Update the RTM and execution summary after the cycle.
